# Change log

This log starts with this publication.
Append one entry when a durable fact changes.
Do not change an older entry.

## How to write an entry

Use these fields.

- Date: the date of the change.
- Evidence: the issue, the command, or the file that shows the change.
- Change: the files that you changed.
- Check: the command that you ran, and the result.

Do not put a home-directory path in an entry.
Do not record a command that you did not run.
